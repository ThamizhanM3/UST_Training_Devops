    2. Shell Script
        1. Disk usage alert
            Problem Statement:
                1. The program must monitor the disk usafe
                2. When a threshold is met, the program must alert the user
                3. The progeam must timestamp each process logs
            Program:
                #!/bin/bash

                threshold=1
                log="monitor.log"
                timeStamp=$(date +"%Y-%m-%d_%H-%M-%S")
                df -hP | grep -vE "^Filesystem|tmpfs|udev" | while read line; do
                usage=$(echo $line | awk '{print $5}' | sed 's/%//')
                partition=$(echo $line | awk '{print $6}')
                if [ "$usage" -ge "$threshold" ]; then
                message="$timeStamp Alert: disk usage on $partition is ${usage}% (Threshold" ${threshold}%)"
                echo "$message" >> "$log"
                echo "$message"
                fi
                done
